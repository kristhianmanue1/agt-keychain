# ADR de procedencia Skevi

Los ADR-018 y ADR-019 de este directorio proceden de Skevi, revisión
`d7a80b26962cd66a806943ff46f779de14c16708`. Se copiaron para resolver
referencias de la guía adoptada. **No son decisiones arquitectónicas de
Llavero** ni autorizan operaciones locales. Los enlaces hacia antecedentes
históricos no copiados apuntan al commit fijado del origen.

Las decisiones propias de Llavero se registran por separado; su diseño actual
se identifica en `.skevi/architecture-overview.md`. Los ADR propios son el
[ADR-020](ADR-020-aprobacion-prop-009.md) (aprobación de PROP-009 sin inicio
de ejecución, 2026-10-17) y el
[ADR-021](ADR-021-presupuesto-lectura-1620.md) (presupuesto de ruta de
lectura a 1620 líneas al actualizar la adopción Skevi a v1.5.0, 2026-10-17).
