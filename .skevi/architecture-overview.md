# Arquitectura de Llavero — índice

La documentación de diseño existente vive en:

- `docs/threat-model-v1.md`: fronteras de confianza y límites de exposición.
- `docs/contracts/credential-delivery-v1.md`: contrato neutral propuesto, aún
  no adoptado.
- `docs/icloud-sync.md`: mecanismo opcional implementado localmente, pendiente
  de firma, activación y validación entre equipos.

El runtime es Python y usa Keychain de macOS. Skevi aporta método de trabajo y
verificación documental; no es una dependencia del runtime. Este índice no
declara cerrada F1 ni transforma los documentos existentes en ADR aceptados.
